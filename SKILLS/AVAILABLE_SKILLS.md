# 📚 Доступные ИИ-скиллы (AI Skills)

В директории `SKILLS` находятся различные навыки (скиллы), конфигурации и фреймворки, расширяющие возможности ИИ-агента. Этот файл служит справочником для понимания того, когда и как их использовать.

## 🎨 Визуальная часть (Фронтенд)

1. **apple-design**
   - **Путь**: `Визуальная часть (Фронтенд)/apple-design`
   - **Когда использовать**: При проектировании или ревью интерфейсов, основанных на жестах (свайпы, drag/drop), пружинных анимациях (springs), полупрозрачных материалах и эффектах глубины в стиле Apple. Идеально для мобильных интерфейсов Telegram Mini Apps.

2. **ui-ux-pro-max-skill**
   - **Путь**: `Визуальная часть (Фронтенд)/ui-ux-pro-max-skill`
   - **Когда использовать**: Для обеспечения "design intelligence". Используйте для аудита UI (accessibility, контраст, размеры кликабельных зон) и получения профессиональных цветовых палитр, типографики и UX-практик при разработке на React, TailwindCSS, Framer Motion и др. Помогает сделать интерфейс "premium".

3. **taste-skill**
   - **Путь**: `Визуальная часть (Фронтенд)/taste-skill`
   - **Когда использовать**: Чтобы избежать "дешевого" или шаблонного ИИ-дизайна (AI slop). Скилл содержит дизайн-направления и правила для более осмысленного, дорогого и атмосферного интерфейса. Отлично сочетается с кинематографичным стилем казино.

## 🤖 Оркестрация агентов

1. **ruflo (ранее Claude Flow)**
   - **Путь**: `Оркестрация агентов/ruflo`
   - **Когда использовать**: При необходимости запуска нескольких специализированных агентов (рой агентов) для выполнения сложных многоуровневых задач. 

2. **claude-squad**
   - **Путь**: `Оркестрация агентов/claude-squad`
   - **Когда использовать**: Для параллельного управления и запуска различных ИИ-агентов, каждый из которых работает в изолированном workspace (использует tmux и git worktrees). Полезно для разделения задач.

3. **awesome-claude-code-subagents**
   - **Путь**: `Оркестрация агентов/awesome-claude-code-subagents`
   - **Когда использовать**: Это библиотека из 100+ готовых субагентов-экспертов (например, `typescript-pro`, `security-penetration-tester`). Используйте, если требуется помощь узкого специалиста для конкретной задачи (ревью безопасности, DevOps скрипты и т.д.).

## 🧠 Оптимизация контекста

1. **claude-context**
   - **Путь**: `Оптимизация контекста/claude-context`
   - **Когда использовать**: MCP-сервер для семантического поиска по кодовой базе. Позволяет агенту находить нужные фрагменты кода в больших проектах без загрузки всего проекта в контекст.

2. **ccusage**
   - **Путь**: `Оптимизация контекста/ccusage`
   - **Когда использовать**: Для отслеживания использования токенов и оценки стоимости работы агента. Это CLI-утилита, генерирующая отчеты о потреблении.

3. **SuperClaude_Framework**
   - **Путь**: `Оптимизация контекста/SuperClaude_Framework`
   - **Когда использовать**: Фреймворк, добавляющий slash-команды, когнитивные роли (архитектор, безопасник) и улучшающий управление сессией. Используйте для структурирования процесса разработки сложных фич.

4. **caveman**
   - **Путь**: `Оптимизация контекста/caveman`
   - **Когда использовать**: "Зачем много токенов, когда можно мало?" Скилл, который заставляет ИИ общаться максимально сжато и по делу (в стиле "пещерного человека"), значительно экономя токены и время генерации ответа.

## ⚙️ Управление воркфлоу

1. **GSD (Get Shit Done)**
   - **Путь**: `Управление воркфлоу/get-shit-done`
   - **Когда использовать**: Фреймворк для Spec-Driven Development. Разбивает большие проекты на атомарные задачи для предотвращения "context rot" (деградации контекста). Применяйте для структурированного выполнения фаз проекта.

---
**Важно**: Перед использованием любого скилла ознакомьтесь с его `README.md` или `SKILL.md` файлом в соответствующей директории.
