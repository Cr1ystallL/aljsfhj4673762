# Правила для ИИ (AI Instructions)

Эти правила обязательны для выполнения любым ИИ-ассистентом, работающим с данным проектом.

## 1. Автоматический Git Commit & Push
- После любого изменения файлов в локальном проекте (написание кода, редактирование скриптов, изменение конфигурации и т.д.), ИИ **ОБЯЗАТЕЛЬНО** должен выполнить команды для сохранения изменений в Git:
  `git add .`
  `git commit -m "описание того, что было сделано"`
  `git push`
- ИИ не должен ждать отдельной просьбы от пользователя на отправку кода. Изменил файлы -> сделал коммит -> запушил.

## 2. Форматирование команд для пользователя
Поскольку ИИ работает на локальном компьютере, а код деплоится и запускается на удаленном сервере (VPS) через SSH, ИИ должен:
- Все команды, которые пользователю нужно выполнить на сервере, выдавать в **ОДНОМ** сплошном bash-блоке ` ```bash ... ``` ` в самом конце своего ответа.
- Это нужно для того, чтобы пользователь мог нажать кнопку "Скопировать" один раз и вставить весь сценарий в терминал.
- Внутри bash-блока команды должны быть прокомментированы (что делает каждый шаг).
- Там, где уместно, использовать полные пути к утилитам (например, `/usr/sbin/ufw` вместо `ufw`), чтобы избегать ошибок с `PATH`.
- Не пытаться выполнить команды для удаленного сервера локально через `run_command`. Локально ИИ может работать только с локальными файлами проекта и git.
